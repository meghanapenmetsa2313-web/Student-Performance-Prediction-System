# Student-Performance-Prediction-System

Developed a machine learning-based system to predict student academic performance using factors such as attendance, study hours, assignment scores, previous grades, and absences. Implemented algorithms including Random Forest, Decision Tree, Logistic Regression, and Naive Bayes to classify students into High, Medium, and Low performance categories. Performed data preprocessing, feature selection, model training, and evaluation using Python and Scikit-learn, achieving high prediction accuracy. The system helps educational institutions identify at-risk students early and supports data-driven academic decision-making.
